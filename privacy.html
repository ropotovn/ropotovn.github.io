Privacy Policy

Hermes Workspace · Last updated 25 November 2026

This Privacy Policy describes how Hermes Workspace ("the application", "the tool") handles information obtained through Google APIs. The application is a private, single-user automation utility operated by its owner for the owner's own Google account. It is not offered as a public service and has no users other than its owner.

1. Information the application accesses

With the owner's explicit consent, the application accesses the following data in the owner's own Google account:

Google serviceScopePurpose
Gmailgmail.readonly, gmail.modify, gmail.sendRead the owner's own mail, prepare drafts and send notifications to the owner.
Google DrivedriveRead and write files in the owner's own Drive.
Google SheetsspreadsheetsRead and update the owner's own spreadsheets (marketplace analytics workbooks).
Google CalendarcalendarRead the owner's own calendar to build a daily schedule.
Google DocsdocumentsRead and write the owner's own documents.
Google Contactscontacts.readonlyResolve the owner's own contact names when addressing messages.

2. How the information is used

Accessed data is used solely to perform tasks requested by the owner on the owner's own machine: updating spreadsheets and documents, preparing and sending email, and reading calendar events. The application does not use the data for advertising, profiling, credit assessment, or any purpose unrelated to the owner's direct request.

3. Storage and retention

  • OAuth credentials (access and refresh tokens) are stored locally on the owner's own computer, in a file readable only by the owner's operating-system account.
  • Data retrieved from Google is held only in memory or in the owner's own local working files for as long as needed to complete the task, and is not retained on any server operated by a third party.
  • The owner can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens.

4. Sharing and disclosure

No Google user data is sold, rented, transferred, or disclosed to any third party. The application does not operate a backend service that receives Google user data. Data may be transmitted only to the Google APIs themselves, which is inherent to performing the requested action.

5. Security

All communication with Google APIs uses HTTPS. Credentials are stored with file permissions restricted to the owner's user account. The application requests only the scopes needed for the functions listed above.

6. Children

The application is not directed to children and does not knowingly collect information from children.

7. Changes to this policy

Any future change will be published on this page with an updated revision date.

8. Contact

9. Google API Services User Data Policy

Hermes Workspace's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
